What I built

One generic decision engine. Each business process is a versioned JSON workflow: loan application (v1 and v2), insurance claim, vendor approval and employee onboarding. For each request, the platform:

  • validates it and blocks duplicates;
  • pins it to the active rules version;
  • runs it stage by stage, calling simulated external services such as a credit bureau, a document verifier and sanctions screening;
  • saves progress atomically after every stage;
  • ends in Approved, Rejected or Manual review, or waits and retries automatically if a service is down.

Every decision comes with a step-by-step explanation and a tamper-evident audit trail.

Constraints satisfied

ConstraintHow
Tolerate requirement changesNew config version and hot reload. Example: the v2 credit threshold changed 650 → 700 with no code change, and in-flight requests stay on v1.
Simulate an external dependencyThree simulated services, with fault injection for errors, timeouts, outages and latency.
IdempotencyIdempotency-Key plus a payload hash, enforced by a database UNIQUE constraint. In a test, 12 concurrent duplicates produce 1 record and 1 external call.
Full audit logsHash-chained per request. Records every rule's values, every dependency attempt, every state change and every human decision.
Configurable without code rewriteThe employee onboarding workflow needed zero lines of code. Configs are validated at load (cycles, references, operators).
Scaling considerationsStateless workers, leases and a queue-based async path, Postgres with SKIP LOCKED, audit partitioning (report §14).

Verified results

Test suite: OK, 85 tests in about 1 second. It also passes on a fresh clone of the repository.

Run it

git clone https://github.com/billbented/resilient-decision-system
cd resilient-decision-system
python3 -m unittest discover -s tests -t .     # 85 tests
python3 -m decision_platform demo               # 14 explained scenarios
python3 -m decision_platform serve              # REST API on :8080

Requires Python 3.10+ only. Implementation: 2,414 lines of platform code.
